## The bindings moved

The Python bindings for ArcadeDB that HumemAI built now live in ArcadeDB's own organization, as [ArcadeData/arcadedb-python](https://github.com/ArcadeData/arcadedb-python). The docs are at [docs.arcadedb.com](https://docs.arcadedb.com/arcadedb-python/), and the old docs address, `docs.humem.ai/arcadedb`, redirects there.

## What changed

The package is [`arcadedb`](https://pypi.org/project/arcadedb/) on PyPI, the native build, which needs no Java. [`arcadedb-jvm`](https://pypi.org/project/arcadedb-jvm/) is the build with a bundled Java runtime. The package used to be called `arcadedb-embedded`.

Install it with `uv add arcadedb`. The import is `import arcadedb`. A development release is on PyPI. The first stable one ships with ArcadeDB 26.11.1.

## Who does what

ArcadeData owns ArcadeDB, and with it the official Python package. HumemAI wrote the bindings, and Taewoon Kim maintains the repository. HumemAI also sends fixes to the engine and runs [DBBench](/research/dbbench), an open benchmark of database engines.

The [SciPy paper](/research/arcadedb-python) about the bindings was written before the move, so it uses the old package name, `arcadedb-embedded`.
