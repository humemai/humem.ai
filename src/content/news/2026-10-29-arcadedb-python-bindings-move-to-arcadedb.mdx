## Working more closely with ArcadeData

HumemAI and ArcadeData are working more closely together, and the Python bindings show it. The repository HumemAI built them in has moved to ArcadeDB's own organization, as [ArcadeData/arcadedb-python](https://github.com/ArcadeData/arcadedb-python). The docs moved into the ArcadeDB docs, at [docs.arcadedb.com](https://docs.arcadedb.com/arcadedb-python/), and the old docs address, `docs.humem.ai/arcadedb`, redirects there.

## What changed

The package is [`arcadedb`](https://pypi.org/project/arcadedb/) on PyPI, the native build, which needs no Java. [`arcadedb-jvm`](https://pypi.org/project/arcadedb-jvm/) is the build with a bundled Java runtime. Both are published from the new repository.

Install it with `uv add arcadedb`. The import is `import arcadedb`. A development release is on PyPI. The first stable one ships with ArcadeDB 26.11.1.

## Who does what

ArcadeData owns ArcadeDB, and with it the official Python package. HumemAI wrote the bindings, and Taewoon Kim maintains the repository. HumemAI keeps sending fixes to the engine and runs [DBBench](/research/dbbench), an open benchmark of database engines.

The [SciPy paper](/research/arcadedb-python) describes the bindings in detail.
